# 안명숙 — 사람과 공간 사이

부동산컨설턴트이자 부동산 마케터, (주)빈파트너스 대표 안명숙의 한국어 브랜드 홈페이지입니다.

## 실행

빌드와 패키지 설치가 필요 없습니다. 저장소 최상위의 `index.html`을 브라우저로 열면 됩니다. HTML, CSS, JavaScript와 직접 제작한 SVG 일러스트만 사용하며 외부 폰트나 라이브러리는 없습니다.

## 수정

- `index.html`: 소개, 문구, 블로그·연락처 링크
- `styles.css`: 색상, 글꼴, 간격과 모바일 레이아웃
- `script.js`: 모바일 메뉴와 저작권 연도
- `city.svg`: 도시 일러스트

이야기 글은 story/posts.json에서 관리합니다. 홈은 날짜 내림차순으로 최대 3개를 자동 표시하며, 현재는 원본 샘플 2개가 있습니다. story/admin.html은 제공된 원본입니다. 연락하기는 https://bin-partners.com 으로 연결됩니다.

## GitHub Pages

저장소 Settings → Pages에서 Deploy from a branch를 선택하고 `main` 브랜치의 `/ (root)`를 지정하면 정적 사이트로 게시할 수 있습니다. 저장소 공개 범위 및 계정 요금제에 따라 Pages 이용 가능 여부가 달라질 수 있습니다.
